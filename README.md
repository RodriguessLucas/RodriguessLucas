## 👨‍💻 Sobre mim

Desenvolvedor Full Stack com experiência prática em aplicações **web, mobile e APIs de ponta a ponta**. No backend, trabalho principalmente com o ecossistema **Java / Spring Boot**; no frontend, com **Angular, React, Next.js e React Native**.

Tenho forte vivência em **modelagem de dados relacionais e NoSQL**, **microsserviços** e **automação com Docker e CI/CD**, entregando produtos para clientes reais: SaaS, plataformas educacionais e sistemas institucionais. Cursando Ciência da Computação na **UFC** (6º semestre), em Fortaleza / Russas, CE 🇧🇷.

Gosto de **medir antes de otimizar**: performance guiada por métricas, não por palpite.

- **Docker, GitHub Actions, Shell, Cloudflare, Vercel e Oracle Cloud:** CI/CD, VPS, backups automatizados e deploy.
- **Práticas:** Scrum, testes automatizados, SEO técnico, PageSpeed Insights e Google Search Console.

## ⚙️ Destaques técnicos

> Os projetos da consultoria onde atuo são confidenciais, então descrevo o problema e a solução, sem nomes de clientes.

- **Performance full stack (Next.js + MongoDB):** listagens paginadas de **8–11s para menos de 1,5s**, com *batch fetching*, desnormalização para busca por índice composto, paginação *pré-join* e paralelismo de requisições no frontend.
- **Topologia de infraestrutura:** unifiquei a região dos serviços (Vercel, Render e MongoDB Atlas) para remover a latência de rede transcontinental.
- **Sistema financeiro do zero (Angular + Spring Boot):** dashboard analítico, simuladores em tempo real, geração automatizada de PDFs e OAuth com 2FA.
- **Plataforma de gestão para escritórios de advocacia:** módulo financeiro completo, processos em Kanban e relatórios em PDF personalizados.
- **App educacional gamificado (React Native + Angular + Java + PostgreSQL):** publicado nas duas lojas, com flashcards de repetição espaçada.
- **Marketplace SaaS:** chat integrado, *match* por geolocalização e avaliações.
- **Backups automatizados:** Shell Script conteinerizado com Docker e GitHub Actions, exportando diariamente para o Google Drive.
