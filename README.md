## ⚙️ Destaques técnicos

> Os projetos da consultoria onde atuo são confidenciais, então descrevo aqui o problema e a solução, sem nomes de clientes.

- **Performance full stack (Next.js + MongoDB):** listagens paginadas que levavam **8–11s caíram para menos de 1,5s**. O ganho veio de eliminar N+1 com *batch fetching*, desnormalizar dados para busca por índice composto, fazer paginação *pré-join* e paralelizar requisições no frontend.
- **Topologia de infraestrutura:** unifiquei a região dos serviços (Vercel, Render e MongoDB Atlas) para remover a latência de rede transcontinental entre eles.
- **Sistema financeiro do zero (Angular + Spring Boot):** dashboard analítico, simuladores financeiros em tempo real, geração automatizada de PDFs e autenticação OAuth com 2FA.
- **Plataforma de gestão para escritórios de advocacia:** módulo financeiro (entradas, saídas, repasses, apuração de lucro por cliente, processo e colaborador), processos em Kanban e relatórios em PDF personalizados.
- **App educacional gamificado (React Native + Angular + Java + PostgreSQL):** publicado nas duas lojas, com flashcards de repetição espaçada.
- **Marketplace SaaS:** chat integrado, *match* por geolocalização e sistema de avaliações.
- **Backups automatizados:** rotina em Shell Script conteinerizada com Docker e GitHub Actions, exportando diariamente para o Google Drive sem intervenção manual.
